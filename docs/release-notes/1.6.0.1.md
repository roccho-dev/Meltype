# Meltype fork 1.6.0.1（候補）

上流の Meltype 1.6.0 を取り込み、この fork の Direct TTY と提案入力の接続を新しい入力セッションへ移植しました。
変換エンジン・辞書・Windows の入力改善は、上流 1.6.0 の変更を引き継ぎます。

Windows に通常インストールする ZIP に加え、ポータブル版の ZIP を提供します。
ポータブル版は Meltype キーボードで動作し、Meltype IME の登録・Windows の起動登録・アプリ内更新を行いません。
設定・学習・辞書は通常は実行ファイルの隣の `data` に保存します。

通常版の自動更新は、この fork の Release から取得したものだけを使います。
ポータブル版では、以前の通常版が残したダウンロード済みの更新も実行しません。

候補のビルド・検証と公開を分け、公開時は検証済みの同じ ZIP を使います。
